# JoeSeven 2.0 — Soluções Web

Site institucional da **JoeSeven**, empresa de desenvolvimento de software, sites e marketing digital. Aplicação moderna em React + TypeScript com foco em performance, SEO e conversão.

🔗 **Demo:** https://joeseven2-0.vercel.app

## ✨ Funcionalidades

- Hero com CTAs de orçamento e contato via WhatsApp
- Seções de serviços, diferenciais, processo, cases, tecnologias e FAQ
- Layout responsivo com animações (Framer Motion)
- Componentes acessíveis com Radix UI / shadcn/ui
- SEO e sitemap configurados

## 🛠️ Tecnologias

- **React 19** + **TypeScript**
- **TanStack Start / Router / Query**
- **Tailwind CSS v4**
- **shadcn/ui** (Radix UI) · **Framer Motion** · **Lucide Icons**
- **React Hook Form** + **Zod**
- **Vite** · ESLint · Prettier
- Deploy na **Vercel**

## 📁 Estrutura

```
src/
├── components/   # componentes de UI e seções
├── hooks/        # hooks customizados
├── lib/          # utilitários
├── routes/       # rotas (TanStack Router)
└── styles.css
```

## ▶️ Como rodar

```bash
git clone https://github.com/LucasM07-2001/joeseven2.0.git
cd joeseven2.0
npm install
npm run dev
```
